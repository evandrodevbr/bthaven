# BTHaven brand assets

The initial mark is an original, editable SVG set for the open-source project:

- `bthaven-mark.svg` — square app/repository mark;
- `bthaven-horizontal.svg` — README and website lockup;
- `bthaven-icon.svg` — simplified icon source for future Windows packaging.

The visual language combines a Bluetooth glyph with a protected harbor/orbit: the computer is the local haven where devices and audio routes meet. Colors are intentionally close to Windows blue while remaining project-owned.
